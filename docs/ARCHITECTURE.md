## Memory

### Objetivo

Responsável por armazenar, organizar e recuperar as informações que o DaviOS precisa lembrar.

### Responsabilidades

- Armazenar memórias.
- Organizar memórias.
- Classificar informações.
- Recuperar memórias relevantes.
- Controlar a importância das memórias.
- Gerenciar o tempo de vida das memórias.

### Dependências

- Database
- Memory Models

### Fornece

- Criação de memórias.
- Recuperação de memórias.
- Consulta de informações armazenadas.

### Não deve fazer

- Controlar o sistema operacional.
- Controlar ferramentas externas.
- Definir a personalidade do DaviOS.
- Conversar diretamente com o usuário.
